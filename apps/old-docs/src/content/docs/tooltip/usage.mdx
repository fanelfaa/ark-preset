## Usage

Import the components:

```tsx
import { Tooltip, TooltipTrigger, TooltipContent } from "~/components/tooltip";
```

Basic tooltip:

```tsx
<Tooltip>
  <TooltipTrigger>Hover me</TooltipTrigger>
  <TooltipContent>Tooltip content</TooltipContent>
</Tooltip>
```

## Advanced Usage

When the composite <InlineCode>Tooltip</InlineCode> doesn't provide enough control, import the raw primitive parts via <InlineCode>TooltipBase</InlineCode>:

```tsx
import { TooltipBase } from "~/components/tooltip";
```

Or import directly from the base file:

```tsx
import { Tooltip } from "~/components/tooltip/tooltip.base";
```
