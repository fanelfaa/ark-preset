## Advanced Usage

### Root Provider

Use `DialogBase.RootProvider` when you need to access the dialog state outside of the component tree. This pattern uses the `useDialog` hook from Ark UI to create a shared context that both the component and external elements can reference.

<ComponentPreview code={DialogRootProviderDemoCode}>
  <DialogRootProviderDemo client:load />
</ComponentPreview>

The key difference:

- **`Dialog`** — manages its own state internally. Use for simple, self-contained usage.
- **`DialogBase.RootProvider`** — accepts a pre-created context via `useDialog`. Use when you need to read or control the dialog state from outside the component tree.
