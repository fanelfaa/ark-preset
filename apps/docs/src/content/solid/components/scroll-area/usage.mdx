### Both Orientations

Allow scrolling in both vertical and horizontal directions with `orientation="both"`:

```tsx
<ScrollArea class="h-72 w-96 rounded-md border" orientation="both">
  <div class="w-[600px] p-4">
    {/* Content that overflows both horizontally and vertically */}
  </div>
</ScrollArea>
```

## Advanced Usage

For full control over the scroll area structure, import the primitive parts via `ScrollAreaBase`:

```tsx
import { ScrollArea, ScrollAreaBase } from "~/components/ui";

// ScrollAreaBase provides direct access to parts:
// ScrollAreaBase.Root, ScrollAreaBase.Viewport, ScrollAreaBase.Content,
// ScrollAreaBase.Scrollbar, ScrollAreaBase.Thumb, ScrollAreaBase.Corner
```

See the [Manual](#manual) installation section for example usage of the primitive parts.
