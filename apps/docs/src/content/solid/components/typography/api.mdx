## API Reference

| Component | Renders As | Description |
| --------- | ---------- | ----------- |
| `Heading` | `<h1>` to `<h4>` | Headings based on `level` prop |
| `Paragraph` | `<p>` | Paragraph text |
| `TextLead` | `<p>` | Lead/introductory text |
| `TextLarge` | `<div>` | Large body text |
| `TextSmall` | `<small>` | Small/fine print text |
| `TextMuted` | `<p>` | Muted/secondary text |
| `TextInlineCode` | `<code>` | Inline code snippet |
| `TextBlockquote` | `<blockquote>` | Quoted content |
| `TextList` | `<ul>` | Unordered list container |
| `class` | `string` | All components accept class |
