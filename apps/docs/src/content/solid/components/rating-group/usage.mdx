## Advanced Usage

When the composite `RatingGroup` doesn't provide enough control, import the raw primitive parts from the base file directly:

```tsx
import { RatingGroup, useRatingGroupVariant } from "~/components/rating-group/rating-group.base";
```

Or import `RatingGroupBase` (the raw parts namespace) from the composite entry point:

```tsx
import { RatingGroupBase } from "~/components/rating-group";
```
