## Usage

Import the component and use it inline:

```tsx
import { RatingGroup, RatingGroupLabel } from "~/components/rating-group";
```

Basic star rating with 5 stars:

```tsx
<RatingGroup count={5} defaultValue={3}>
  <RatingGroupLabel>Rate this</RatingGroupLabel>
</RatingGroup>
```

## Advanced Usage

When the composite <InlineCode>RatingGroup</InlineCode> doesn't provide enough control, import the raw primitive parts from the base file directly:

```tsx
import { RatingGroup, useRatingGroupVariant } from "~/components/rating-group/rating-group.base";
```

Or import <InlineCode>RatingGroupBase</InlineCode> (the raw parts namespace) from the composite entry point:

```tsx
import { RatingGroupBase } from "~/components/rating-group";
```
