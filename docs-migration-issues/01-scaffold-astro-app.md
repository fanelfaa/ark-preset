## What to build

Initialize a new Astro application (`apps/new-docs`) alongside the existing `apps/docs`. Port over the Tailwind configuration, Typography plugin, and the shell layout (`DocsLayout.tsx`) from the old site to ensure brand consistency. Set up the Playwright testing harness and write a basic test verifying the layout renders correctly.

## Acceptance criteria

- [ ] `apps/new-docs` is initialized as an Astro project.
- [ ] Tailwind CSS and the Typography plugin are configured matching the old site.
- [ ] `DocsLayout.tsx` is successfully ported over and renders without errors.
- [ ] Playwright E2E testing is configured.
- [ ] A basic E2E test verifies the layout renders correctly.

## Blocked by

None - can start immediately
