## What to build

Set up Astro Content Collections for the `solid`, `react`, and `vue` frameworks. Build the dynamic route (`src/pages/[framework]/components/[component].astro`) to serve the MDX files. Add a functional "Framework Selector" in the navbar that redirects between framework paths, and write an E2E test to verify routing.

## Acceptance criteria

- [ ] Astro Content Collections are configured for `solid`, `react`, and `vue`.
- [ ] A dynamic route handles rendering MDX files based on the framework path.
- [ ] A Framework Selector is added to the navbar to switch between frameworks.
- [ ] E2E tests verify that navigating to different framework paths works correctly.
